# 線上展間 Art Gallery

一間可以在瀏覽器裡逛的 3D 古典展廳：挑高拱頂與天窗、白色壁柱、拱窗、舊木地板，長廊盡頭穿過拱門是一間明亮的後殿。
支援滾動導覽、自由走動、上傳作品掛進畫框、作品說明牌。
純靜態網站（`index.html` + `config.js`），不需要建置步驟，可直接用 GitHub Pages 發布。

## 功能

- **導覽**：向下滑動，鏡頭依序走到 12 件作品前，顯示標題與介紹。
- **自由走動**
  - 鍵盤：方向鍵或 WASD 移動，Q／E 轉頭
  - 觸控板／滾輪：雙指上下滑＝前進後退，左右滑＝轉向
  - 滑鼠：拖曳轉頭
  - 手機：左下搖桿移動，拖曳畫面轉頭
- **上傳作品**（管理員）：右上「登入」後變成「＋ 上傳作品」，選畫框、選圖片、填標題／作者／年份／媒材／介紹。畫框會依圖片比例自動調整，圖片會先縮到長邊 1600px。
- **上傳前校正**：選好圖片後會進入校正畫面，只做三件事，不加濾鏡、不重新上色：
  - 拖曳四個角對齊畫作，裁掉牆面並把歪斜的透視拉正
  - 白平衡：點一下畫面中本來應該是白色或中性灰的地方，去掉色偏
  - 壓低反光：把過亮的地方壓暗（反光無法真的移除，拍攝時避開光源效果最好）
- **作品標註**：每幅畫旁有說明牌；點畫作、說明牌或編號圓點可看完整資訊。

## 展廳

光從左側來：左牆有落地拱窗和一道通往戶外的拱形開口，陽光在舊木地板上投出窗格的光影；右牆只掛畫。
節奏是兩幅畫隔一扇窗，左右不對稱。長廊盡頭穿過拱門是後殿。

## 發布到 GitHub Pages

Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`。

## 共用儲存（Supabase）

`config.js` 已填上 Supabase 專案的網址與 publishable key：所有訪客看到同一批作品，**只有管理員能上傳、更換、移除**。

- **成為管理員**：在網站按「登入」→ 輸入 Email 與密碼 →「第一次使用：建立帳號」→ 點確認信裡的連結 → 回來按「登入」。
  第一個完成登入的帳號會成為唯一的管理員，之後其他人就算註冊也沒有上傳權限。
- **資料庫結構與權限**：[`supabase/setup.sql`](supabase/setup.sql)。要搬到另一個 Supabase 專案時，在 SQL Editor 整份執行，再把新的網址與 key 填進 `config.js`。
- **防止免費專案被暫停**：[`.github/workflows/keepalive.yml`](.github/workflows/keepalive.yml) 每天對資料庫發一次唯讀請求。
  GitHub 會在 repo 連續 60 天沒有任何活動時停用排程，屆時到 Actions 頁面重新啟用即可。
- `config.js` 兩個欄位留空時，作品只存在訪客自己的瀏覽器（IndexedDB），不需要登入。

注意：

- publishable key 本來就是放在前端的公開金鑰，權限由資料庫的 RLS 規則把關；**不要**把 `service_role`／secret key 放進這個 repo。
- 換圖時舊圖檔會留在儲存桶裡，需要時可在 Supabase 後台清理。

## 自訂

- 畫框位置與數量：`index.html` 裡的 `SLOTS`（改數量時，`setup.sql` 的 `slot between 0 and 11` 也要一起改）。
- 展廳尺寸：`W`（寬）、`H`（牆高）、`RISE`（拱頂高度）、`ZF`／`ZB`（前後牆位置）；後殿是 `AW`／`AD`／`AH`。
- 牆面、地板、壁柱、拱窗、拱頂與天窗：`buildRoom()`。窗戶位置是 `WINZ`，戶外開口是 `DOORZ`，地上的陽光是 `sunPatch()`。
- 可以走到哪裡：`walkable()`。左牆的拱形開口目前只能走到門檻；之後要加戶外空間，就是在門外建場景、在這裡多放行一塊區域。
- 預設示範畫是程式生成的（`genArt()`），不含任何外部圖片。

## 技術

[Three.js](https://threejs.org) r128（從 cdnjs 載入）、原生 JavaScript、Supabase REST／Storage API（選用）。
展廳是用程式搭建的幾何，沒有使用外部 3D 模型。
